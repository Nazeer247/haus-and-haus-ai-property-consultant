# Haus & Haus — AI Property Consultant Demo

An independent, responsive concept demonstrating a guided AI-style property discovery experience for Dubai real estate website visitors.

## Included
- Premium responsive landing page
- Guided buy / rent / invest discovery flow
- Area, budget, bedroom, property type and timing qualification
- Copyable enquiry brief for a human property specialist
- Mobile-friendly layout and navigation

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Important demo limitations
- This is an independent concept, not an official Haus & Haus product.
- The assistant uses scripted demo logic; no live AI model is connected.
- No live listings, CRM, appointment calendar, or lead delivery is connected.
- Answers are processed in the browser and are not sent to a server by this demo.
- Any property imagery is illustrative and does not represent a listing.

## Deployment
The project is static and can be deployed using Cloudflare Pages by connecting this GitHub repository. Use the repository root as the project directory; no build command is required.
